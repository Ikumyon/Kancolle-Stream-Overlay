# Kancolle Stream Overlay

艦これ配信用の多機能ブラウザ拡張機能（Manifest V3）です。

## 主な機能

- **タイマー機能**: 手動入力・プリセット・自動表示・完了通知に対応。疲労回復時間の計算（母港給糧艦オプション対応）。
- **情報パネル & コントロールパネル**: ドラッグ＆ドロップによる位置変更およびリサイズ。設定の保存と復元。
- **出撃情報表示**: 海域、難易度、進行状態、自由記述、ドロップカウントなどのリアルタイム反映。
- **レイアウトカスタマイズ**: 設定画面から行・列・カードの追加・削除、表示形式の調整が可能。
- **BGM/戦果連動**: バックグラウンドでの SSE 接続による BGM 名や戦果の更新機能。

## 使い方

1. 本リポジトリをダウンロード（または `git clone`）します。
2. ブラウザ（Chrome / Edge 等）の拡張機能管理ページ（`chrome://extensions` など）を開きます。
3. **デベロッパーモード** を有効にします。
4. **パッケージ化されていない拡張機能を読み込む** をクリックし、本フォルダを選択します。

## 開発・動作確認

```bash
# 依存スクリプトと設定の整合性チェック・自動テストを実行

```
