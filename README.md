# Kancolle Stream Overlay

艦これ配信用の多機能ブラウザ拡張機能（Manifest V3）です。

## 主な機能

- **タイマー機能**: 時間指定・プリセット・自動表示・完了通知に対応。疲労回復時間の計算（母港給糧艦オプション対応）。
- **Cloudflare (kancolle-notify) 連携**:
  - タイマー開始時に Cloudflare Workers へ終了時間を自動送信。
  - コントロールパネル中段の「`☁`」アイコンから、クラウド上で稼働中の遠征・入渠・疲労度・手動タイマーを一覧取得し、タイマーパネルへ引き継ぎ表示。
  - 停止ボタン押下時、手動タイマーのみクラウド側も削除し、遠征・入渠等の自動タイマーはローカル表示解除のみを行う安全設計。
- **情報パネル & コントロールパネル**: ドラッグ＆ドロップによる位置変更およびリサイズ。設定の保存と復元。
- **出撃情報表示**: 海域、難易度、進行状態、自由記述、ドロップカウントなどのリアルタイム反映。
- **BGM連動**: バックグラウンドでの SSE 接続による BGM 名の更新機能。
- **戦果表示**: 別拡張「KCO 通常戦果リーダー」から通常戦果の推計を受信して表示。日本時間2:00・14:00でリセットします。本体にはゲーム通信の監視処理を含みません。

## 使い方

1. 本リポジトリをダウンロード（または `git clone`）します。
2. ブラウザ（Chrome / Edge 等）の拡張機能管理ページ（`chrome://extensions` など）を開きます。
3. **デベロッパーモード** を有効にします。
4. **パッケージ化されていない拡張機能を読み込む** をクリックし、本フォルダを選択します。
5. **Cloudflare 連携の利用（任意）**:
   - 拡張機能アイコンをクリックして設定画面を開きます。
   - 「タイマー」タブ下部の「Cloudflare連携」セクションで、連携をONにし、`Worker URL` および `認証トークン` を入力・保存します。
   - コントロールパネル中段右端の「`☁`」アイコンをクリックすると、クラウド上のタイマー一覧を取得・選択できます。

## 開発・動作確認

戦果を自動表示する場合は、`KCO_senka_reader` フォルダーを別の拡張として読み込み、ゲームの開発者ツールを開いて母港を表示してください。情報パネルに「戦果」カードを配置すると、観測開始後の経験値由来の推計が届きます。EO・任務・引継ぎ戦果は含みません。詳細は [戦果リーダーの導入手順](KCO_senka_reader/README.md) を参照してください。

```bash
# 依存スクリプトと設定の整合性チェック・自動テストを実行
npm run verify
```

詳細な確認項目については [TESTING.md](TESTING.md) を参照してください。
